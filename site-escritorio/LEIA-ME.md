# Site do escritório

Site de uma página (Início, Perfil, Serviços, Clientes, Contato), feito a partir do enunciado do mini-projeto "Página de Escritório de Contabilidade".

## Como editar
1. Abra `index.html` no Bloco de Notas.
2. Procure `EDITE AQUI` e preencha os dados entre as aspas (nome, telefone, WhatsApp, e-mail, endereço, redes sociais, CRC).
3. Salve e dê dois cliques no `index.html` para ver no navegador. O que ficar vazio aparece como [preencher].

Clientes só entram com autorização deles. Para trocar a ilustração do Perfil por uma foto, coloque a imagem nesta pasta e siga o comentário no arquivo.

## Como publicar
Qualquer hospedagem de site estático serve (Netlify, Vercel, GitHub Pages, Hostinger): envie o `index.html` (e as imagens, se houver).
